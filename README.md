# رواتب.dz — SalaryDZ

خريطة رواتب تشاركية للجزائر. موقع static خالص (HTML/CSS/JS، بلا باك اند، بلا سيرفر) — كل البيانات محفوظة في `salaries.json` وتنمو عبر مساهمات المجتمع مباشرة على GitHub.

## الفكرة

ما كاين منصة تعطي فكرة واضحة و صادقة على الرواتب الحقيقية في الجزائر حسب المهنة والولاية وسنوات الخبرة. رواتب.dz تحل هذا بطريقة بسيطة:

- **بلا فورم، بلا قاعدة بيانات.** كل تصريح راتب هو سطر JSON يضيفه شخص عبر Pull Request.
- **بلا سيرفر.** الموقع HTML/CSS/JS خالص، يتنشر مجانا على GitHub Pages.
- **تحقق تلقائي.** GitHub Action يتأكد أن أي مساهمة جديدة تحترم الفورمات قبل الدمج.

## التشغيل محليا

الملفات تُقرأ عبر `fetch`، فلازم خادم محلي بسيط (المتصفح يمنع قراءة JSON مباشرة من نظام الملفات):

```bash
python -m http.server 8000
# افتح http://localhost:8000
```

## كيفاش تساهم ببيانات

1. افتح `salaries.json` في المتصفح على GitHub واضغط أيقونة القلم (✎) للتعديل.
2. زيد سطرك الجديد في آخر القائمة، بنفس الشكل:

```json
{
  "job_title": "اسم المهنة بالعربية",
  "job_title_en": "Job Title in English",
  "wilaya": "اسم الولاية",
  "wilaya_code": "16",
  "experience_years": 3,
  "salary_min": 60000,
  "salary_max": 90000,
  "company_type": "خاص",
  "date_added": "2026-08-08"
}
```

3. اضغط **Propose changes** ثم **Create pull request**. الـ GitHub Action يتحقق تلقائيا من الفورمات، وإذا كل شيء مليح يتدمج.

## كيفاش تساهم بالكود

الأفكار مرحب بيها بزاف: فلترة إضافية، مقارنة بين الولايات، تصدير الرسم البياني كصورة، تحسين الأداء، ترجمة الواجهة... افتح Issue أو Pull Request مباشرة.

## البنية

```
index.html          الصفحة الرئيسية
style.css           التصميم
script.js           المنطق (فلترة، بحث، رسم بياني)
salaries.json        البيانات — هذا الملف يكبر بمساهماتكم
scripts/validate.js  سكريبت التحقق المستعمل في الـ CI
.github/workflows/   إعداد GitHub Action
```

## الرخصة

المشروع مفتوح المصدر. البيانات المساهم بها تعتبر مجهولة المصدر ولا تحتوي أي معلومة شخصية — رجاء عدم إضافة أسماء أشخاص أو شركات محددة.
